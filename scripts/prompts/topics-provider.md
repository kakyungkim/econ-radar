# econ-radar 지식 노트 갱신 작업

대상 날짜: `{{DATE}}`
선택 제공자: `{{PROVIDER}}`

`vault/daily/{{DATE}}.md`는 이미 완성돼 있다. 데일리와 분석 파일은 고치지 않고 지식 노트만 갱신한다.

1. `vault/daily/{{DATE}}.md`와 `vault/analysis/*-{{DATE}}.md`를 읽는다.
2. 핵심 항목마다 관련 `vault/topics/*.md`(기존 파일 우선)를 찾아 `## 타임라인`의 날짜 순서(최신이 위)에 맞는 자리에 기존 형식대로 `### {{DATE}} [[daily/{{DATE}}]]` 블록과 한두 줄 요약, 관련 주제 링크(`→ [[topics/...]]`)를 넣고 frontmatter `updated`는 `{{DATE}}`가 더 늦을 때만 바꾼다. 이미 `{{DATE}}` 블록이 있으면 다시 넣지 않는다. 흐름이 바뀌었으면 타임라인 위 요약 불릿도 고친다.
3. 새 주제 파일은 기존 파일로 담을 수 없을 때만 같은 frontmatter 형식으로 만든다.
4. `vault/_meta/recent-headlines.md`에 `## {{DATE}}` 블록(핵심 5개, 후속이면 `[후속]`)이 없으면 날짜 순서에 맞게 추가하고 최근 7일치만 남긴다.
5. 데일리에 없는 사실이나 수치를 새로 만들지 않는다. git, 렌더, 발송은 실행하지 않는다.
6. 최종 응답에는 갱신한 주제 파일 목록만 적는다.
