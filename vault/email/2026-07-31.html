Macro

1. 코스피 +17.91% — 역대 최대 단일일 상승, 외국인 7.25조원 쏟아부었다

코스피가 7월 31일 종가 6,595.45로 마감하며 하루 만에 1,001.89포인트(+17.91%) 뛰었다. 한국 증시 사상 최대 단일일 상승률이자 상승폭이다. 종전 기록은 2008년 금융위기 당시(10월 30일) +11.95%였다. 삼성전자는 262,500원(+26.81%), SK하이닉스는 1,718,000원(+29.95%)으로 마감했다. 외국인은 7조2,499억원(본문 확인 필요)을 순매수(역대 최대), 기관도 1조1,522억원을 더했다. 반면 개인은 8조2,500억원(역대 최대)을 순매도했다. 전날 장 마감 후 나온 Amazon AWS +37%·Microsoft Azure +43%가 "AI 데이터센터 투자가 실수요"임을 확인하자, 3거래일 -17% 이상 짓눌렸던 HBM 공급주에 안도 매수와 공포 청산이 동시에 몰렸다. 오전 9시 6분에는 매수 쪽 사이드카(프로그램 매매 5분 일시 정지)도 발동됐다.

2. Replimune RP1 AdCom 10:3 찬성 — 두 번 거절된 종양용해바이러스, 세 번째에서 돌아섰다

FDA 세포·조직·유전자치료 자문위원회(CTGTAC)가 7월 30일 Replimune의 RP1(vusolimogene oderparepvec) + 니볼루맙(nivolumab) 병용요법에 10:3 찬성 투표를 내렸다. RP1은 HSV-1(단순포진 바이러스 1형) 기반 종양용해바이러스(oncolytic virus)로, 2023년 1차·2025년 2차 완전회신서(CRL) 이후 세 번째 도전이다. IGNYTE 단독군 임상의 항PD-1 불응 진행성 흑색종(melanoma) 환자 ORR(객관적 반응률) 36.4%와 반응 지속 기간 데이터를 자문위원 10명이 "임상적으로 의미 있다"고 판단했다. 반대 3명은 단독군 설계의 해석 한계를 들었다. PDUFA는 내일(8월 2일)이다. REPL 주가는 발표 직후 시간외 거래에서 +127% 급등했다.

3. Amazon Q2 AWS +37% — 18분기 최고, 매출 $200.6B 첫 돌파, Anthropic 지분 77조원 평가익

Amazon이 7월 30일 장 마감 후 Q2 2026(1~6월) 실적을 발표했다. 분기 순매출 2,006억달러(약 290조8,700억원)로 사상 처음 2,000억달러(약 290조원) 벽을 넘었다. AWS 클라우드 매출은 422억달러(약 61조1,900억원, +37% YoY)로 18분기 만에 최고 성장률이며 연환산 런레이트(run-rate)는 1,690억달러(약 245조원)에 달한다. AWS 영업마진은 39.4%였다. EPS 5.75달러 중 534억달러(약 77조4,300억원)는 Anthropic 지분 평가이익(비현금 항목)이다. Amazon은 FY2026 설비투자(capex) 전망을 2,200억달러(약 319조원)로 높였는데 메모리 비용 급등이 주된 이유였다. Q3 매출 가이던스 1,970억~2,020억달러(약 285조6,500억~292조9,000억원)는 컨센서스(2,040억달러, 약 295조8,000억원)를 하회했다. AMZN 주가는 시간외에서 약 +9% 상승했다.

4. 미 Q2 GDP +1.5%·PCE +5.1% — 성장 둔화 속 물가 가속, 스태그플레이션 패턴 확인

BEA(미국 경제분석국)가 7월 30일 발표한 Q2 2026 GDP 속보치(Advance Estimate)는 연율 +1.5%로 시장 컨센서스 +2.1%와 Q1 최종치 +2.1%를 동시에 밑돌았다. 성장 둔화는 정부 지출 감소와 수출·투자 둔화에서 비롯됐다. PCE(개인소비지출) 물가지수는 Q2 +5.1%(Q1 +4.6%)로 가속했고, 코어 PCE는 +3.4%(Q1 +4.4%)로 낮아졌지만 Fed 목표치(+2%)의 1.7배다. 에너지 가격(이란 충격) 급등이 물가를 재가속시키는 반면 성장은 꺾이는 전형적 스태그플레이션 패턴이 확인됐다. CME FedWatch 기준 9월 FOMC 25bp 인상 확률은 72.3~82.4% 범위를 유지했다.

5. OpenAI GPT-5.6 Luna API 80% 인하 — AI 모델 원가 전쟁, 경량 모델 상품화 가속

OpenAI가 7월 30일 GPT-5.6 라인업 중 경량 모델 Luna의 API 가격을 입력 1달러→0.20달러/백만 토큰(-80%), 출력 6달러→1.20달러/백만 토큰(-80%)으로 대폭 낮췄다. 중간급 Terra는 입력·출력 각각 -20% 적용, 최고급 Sol은 동결했다. 재원은 Sol의 추론 스택(inference stack) 재설계로 확보한 연산 효율 향상에서 나왔다고 밝혔다. 경쟁 구도: Anthropic Claude Opus 5는 Sol과 유사한 성능이지만 통합 요금(combined rate) 기준 30달러로 Sol 대비 약 6% 저렴하다.
