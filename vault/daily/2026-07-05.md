## 🗣 Today's Topic — 모델 증류(Model Distillation): AI 지식재산 전쟁의 새 전선

Anthropic이 의회에 제출한 서한의 핵심 논점은 구조적 취약성이다. 가짜 계정으로 수개월간 2,880만 건 교신을 이어간 것은 이 공격이 조직적·장기적으로 설계됐음을 보여준다.

모델 증류는 대형 언어 모델(LLM)의 API에 대규모 질문-답변 쌍을 수집한 뒤, 이를 학습 데이터로 삼아 더 작고 저렴한 모델을 훈련하는 기법이다. 원 모델이 보유한 지식과 추론 능력이 더 작은 모델로 증류되듯 이전된다는 데서 이름이 붙었다. 물리적 장치나 코드를 훔치는 것과 달리, API를 통한 증류는 현행 영업비밀법이나 특허법으로 막기가 어렵다.

Anthropic은 기술 접근 차단과 함께 의회 서한을 제출했다. 중국 AI 기업의 API 접근을 제한하는 입법 근거를 쌓으려는 행보로 해석된다. Alibaba가 즉각 "스파이웨어 우려"를 내세워 Claude Code 사용을 금지하고 반박에 나선 것도 같은 맥락으로 풀이된다.

이 분쟁은 AI 산업 구조에 두 가지 흔적을 남긴다. 서방과 중국 AI 모델이 독립된 생태계로 분리되는 속도가 빨라지고, 증류 탐지·속도 제한·지역 IP 차단 같은 방어 체계가 AI 서비스의 기본 운영 비용으로 자리잡는다.

- 💬 한 줄 요약: 모델 증류는 API 입출력 데이터를 대량 수집해 경쟁사 AI를 역설계하는 기법으로, 막기 어렵다는 구조적 특성 때문에 분쟁이 기술이 아닌 법·규제 전선으로 이동하고 있다.

## 🗽 Business English

- **model distillation (모델 증류)**: 대형 AI 모델의 API 입출력 쌍을 대량 수집해 더 작고 저렴한 모델을 학습시키는 기법. 원 모델의 능력이 작은 모델로 증류되듯 이전된다는 데서 이름이 붙었다.
  - 📝 *Anthropic told Congress that Alibaba's researchers used 25,000 fake accounts to conduct model distillation, collecting millions of Claude responses to train a rival AI.* → Anthropic은 Alibaba 연구자들이 가짜 계정 2만 5,000개를 동원해 모델 증류를 수행했다고 의회에 보고했다. 수백만 건의 Claude 응답을 수집해 경쟁 모델 훈련에 쓴 것이다.

- **conditional approval (조건부 승인)**: 규제 기관이 확증 데이터를 추가로 요구하는 조건을 달아 내리는 허가. 시판은 가능하지만 급여 등재와는 별개 절차가 남는다. 의약품 외에도 금융·환경 규제에서도 쓰인다.
  - 📝 *The MHRA granted Wegovy conditional approval for MASH, meaning Novo Nordisk must still submit confirmatory data before the drug becomes a standard NHS-reimbursed treatment.* → MHRA는 Wegovy에 MASH 조건부 승인을 내렸다. Novo Nordisk는 확증 데이터를 추가로 제출해야 NHS 급여 표준 치료로 자리잡을 수 있다.

- **PDUFA date (Prescription Drug User Fee Act target date, 신약 심사 결정 기한)**: FDA가 Prescription Drug User Fee Act(처방의약품 사용자 요금법)에 따라 설정하는 신약 심사 완료 목표일. 바이오텍 투자에서 가장 중요한 단기 이벤트 기준점이다. 이 날짜 전후로 해당 종목의 변동성이 집중된다.
  - 📝 *Vera Therapeutics' PDUFA date for atacicept is July 7, making it the most immediate binary catalyst for IgAN investors this week.* → Vera Therapeutics의 아타시셉트 PDUFA 결정일은 7월 7일로, 이번 주 IgAN 투자자들에게 가장 즉각적인 이진 이벤트다.
