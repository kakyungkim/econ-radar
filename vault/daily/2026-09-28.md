## 🗣 Today's Topic — Mirum brelovitug: HDV 최초 치료제의 분기점

오늘 밤(KST 21:30) brelovitug의 AZURE-1 Phase 3 탑라인 결과가 발표된다. HDV(C형이 아닌 델타 바이러스)는 HBV에 중첩 감염되는 위성 바이러스로, B형간염 보균자 중 심각한 합병증(간경변·간암)으로 이어지는 비율이 높지만 치료 옵션이 극히 제한적이다. 전 세계 감염 추산 1,200만~1,500만 명의 환자가 사실상 치료 대안 없이 병을 안고 사는 상황이다.

Brelovitug은 HBV/HDV 공유 표면 항원(HBsAg)을 표적하는 완전 인간 IgG1 단클론항체다. Phase 2b(AZURE-1 2b구간)에서 300mg 주 1회 투약군이 24주 시점 1차 평가변수(바이러스 반응 + ALT 정상화 복합)를 달성한 선례가 있어, Phase 3 탑라인을 앞두고 투자자·임상의 모두의 기대가 모인다. 성공 시 FDA BLA 제출 경로가 열리고, 희귀의약품 지정(ODD)을 통한 신속 심사 가능성도 있다.

## 🗽 Business English

- **stalemate (교착 상태, 진전 없이 멈춘 상황)**: 협상이나 갈등에서 어느 쪽도 진전을 이루지 못하고 정체된 상태. 체스에서 유래했으나 외교·경제 맥락에서 자주 쓰인다.
  - 📝 *US-Iran talks hit a stalemate after Trump rejected the phased Strait reopening proposal.* → 트럼프가 단계적 해협 재개방 제안을 거부하면서 미-이란 협상이 교착 상태에 빠졌다.

- **binary event (이진 이벤트, 이분법 결과 이벤트)**: 결과가 '양성/음성', '통과/실패' 두 가지로 갈리는 임상·정책·규제 이벤트. 바이오 투자에서 Phase 3 결과나 FDA 결정 전날을 가리킨다.
  - 📝 *The Phase 3 readout is a binary event — a clean win drives the stock up, while a miss sends it sharply lower.* → Phase 3 결과 발표는 이진 이벤트다 — 명확한 성공은 주가를 끌어올리고, 실패는 급락으로 이어진다.
