### 4. GSK Hibsago FDA PDUFA D-4 — CHB 기능적 치유율 19% vs 0%, 세계 최초 승인 시험대

GSK와 Ionis가 공동 개발한 안티센스 올리고뉴클레오타이드(ASO·antisense oligonucleotide) bepirovirsen(Hibsago)의 만성 B형 간염(CHB·Chronic Hepatitis B) FDA 심사 결과(PDUFA)가 10월 26일이다. 일본 의약품의료기기종합기구(PMDA)는 2026년 8월 Hibsago를 세계 최초 CHB 기능적 치유(functional cure) 치료제로 이미 승인했다. Phase 3 B-Well 1·2에서 HBsAg ≤3,000 IU/mL 대상군의 기능적 치유율(HBsAg 소실+항체 전환)은 19%(bepirovirsen) vs 0%(위약)였다. 기존 표준치료인 뉴클레오사이드(t)유사체 기능적 치유율 ~1%와 비교된다. FDA 우선심사·돌파구치료제(BTD·Breakthrough Therapy Designation)·패스트트랙(Fast Track) 3중 지정을 보유한다.

**Key Point**: 일본 선행 승인과 FDA 3중 지정이 긍정적 근거다. 적용 대상이 HBsAg ≤3,000 IU/mL 서브그룹으로 제한돼, 전체 CHB 환자(약 2억9,600만 명) 중 실제 처방 대상 규모는 좁다.
🙋 **Demand**: CHB 환자에게 기능적 치유는 평생 경구 항바이러스 복약에서 벗어날 수 있다는 의미다. 처방의(간 전문의)는 HBsAg 정량 진단(≤3,000 IU/mL 선별) 표준화가 처방 시작의 선행 조건이다. 지불자에게는 완치 달성 시 평생 뉴클레오사이드 유사체 비용 절감이 급여 협상 논거이지만, ICER 분석 결과가 먼저다.
💡 **Insight**: GSK가 세계 최초 기능적 치유 승인자 지위를 확보하면 Arrowhead·Vir·Assembly Biosciences 등 후발 RNAi·캡시드 억제제 경쟁사보다 약가 협상과 가이드라인 편입에서 유리한 위치를 선점하는 구조다.

### 5. 삼성바이오로직스 PolyPeptide 공개매수 87.92% 성사 — GLP-1 API CDMO 진입 확정

삼성바이오로직스의 스위스 PolyPeptide Group AG 전량 공개매수(tender offer) 최종 응모율이 87.92%로 확정됐다. 최소 조건(2/3, 66.67%)을 대폭 초과해 딜 완결이 확정됐다. 딜 규모는 약 14억6,000만 스위스프랑(약 2조2,000억원 추정)으로, 주당 인수가 44.31스위스프랑은 시장가 대비 약 40% 프리미엄이었다. 🙋 **Demand**: PolyPeptide의 직접 고객은 Novo Nordisk·Eli Lilly 등 GLP-1 신약을 판매하는 제약사다. 자체 생산 한계와 수요 급증이 겹쳐 이 고객들의 외부 API CDMO 의존도가 높아진 상태다. M&A 통합 과정의 생산 연속성 유지가 채택 장벽이다.
💡 **Insight**: GLP-1 API 병목이 지속되는 한 협상력은 높지만, 빅파마가 API 내재화를 강화하면 중장기 외부 CDMO 수요가 줄어들 수 있다. 통합 후 대형 고객사와의 장기 공급 계약 체결 여부가 주가 방향을 가를 것으로 보인다.

## 🗣 Today's Topic — GLP-1 펩타이드 원료의약품(API) 공급망

오늘 5번 기사(삼성바이오로직스의 PolyPeptide 인수)를 이해하려면 세마글루타이드·티르제파타이드 같은 GLP-1 계열 약물이 어떻게 만들어지는지, 그리고 왜 원료 공급이 병목이 됐는지를 알아야 한다.

**GLP-1이란**

GLP-1(글루카곤유사펩타이드-1·glucagon-like peptide-1)은 식사 후 소장에서 분비되는 호르몬이다. 인슐린 분비를 촉진하고 식욕을 억제한다. 이 호르몬의 작용을 모방하거나 연장하는 약물이 비만·당뇨 치료제로 폭발적 수요를 얻었다. 대표 약물인 세마글루타이드(오젬픽·위고비), 티르제파타이드(마운자로·젭바운드)는 모두 펩타이드(아미노산이 사슬처럼 연결된 분자)로 만들어진다.

**펩타이드 의약품은 어떻게 생산하나**

펩타이드 의약품의 생산은 크게 두 단계다. 첫 번째는 원료의약품(API) 합성이다. 고상 펩타이드 합성(SPPS·Solid-Phase Peptide Synthesis) 또는 액상 합성법으로 아미노산을 순서대로 결합해 목표 펩타이드 사슬을 만든다. 이 단계는 화학 반응 정밀도와 불순물 제어가 핵심이다. 두 번째는 완제의약품(DP) 제형화다. 주사제 형태로 만들어 포장하는 단계다.

항체(단백질) 의약품은 세포 배양으로 생산하지만, 펩타이드 API는 화학 합성이다. 설비 투자와 기술 장벽이 다르다. 전문 펩타이드 API CDMO가 소수에 불과해, GLP-1 수요가 급증하자 이 단계가 공급망 병목이 됐다.

**왜 공급망이 막혔나**

세마글루타이드 제조사 Novo Nordisk는 2023~2025년 생산 능력 확장에 수십억달러를 투입했음에도 공급 부족이 이어졌다. 이유는 두 가지다. 세마글루타이드는 31개 아미노산으로 구성돼 합성 수율이 낮고 정제가 까다롭다. 기존 펩타이드 API 설비는 성장호르몬·인슐린 등 오래된 시장을 위해 구축돼 있어 GLP-1 대규모 증산에 맞게 빠르게 전환되지 못했다. 결과적으로 빅파마들은 외부 CDMO에 의존하거나 자체 설비를 급속 증설하는 쪽으로 나뉘었다.

**삼성바이오로직스는 왜 PolyPeptide를 샀나**

삼성바이오로직스는 항체·ADC 위탁생산 역량은 갖췄지만 펩타이드 API 합성 역량은 없었다. PolyPeptide는 5개국에 펩타이드 합성 설비를 운용하는 전문 CDMO다. GLP-1 공급망 병목을 해소할 수 있는 외부 역량을 직접 인수했다. 통합 후 항체+ADC+펩타이드 API를 한 파트너에게 맡길 수 있으면, 빅파마는 공급망을 단순화할 수 있다.

단, 리스크도 있다. M&A 통합 기간에 생산 연속성이 흔들리면 기존 고객사가 이탈할 수 있다. 빅파마들이 장기적으로 API를 내재화하면 외부 CDMO 수요가 줄어드는 구조적 역풍도 가능하다.

- 💬 한 줄 요약: GLP-1 펩타이드 의약품의 원료 합성은 소수 전문 CDMO에 집중된 병목 공정으로, 삼성바이오로직스의 PolyPeptide 인수는 이 병목을 직접 해소하기 위한 전략적 인수다.
- 블로그 소재: GLP-1 공급망 전체 지도(API→완제→물류), 펩타이드 합성 vs 항체 생산 기술 차이, K-CDMO가 GLP-1 시장에서 경쟁하는 방법

- **GLP-1 API CDMO — 빅파마 수요**: Novo Nordisk·Eli Lilly의 GLP-1 제품 수요 폭증이 자체 생산 설비를 초과했다. 이 고객들에게는 단가보다 안정적 공급과 규제 수준 품질이 선택 기준이다. 삼성바이오로직스가 통합 과정에서 공급 연속성을 얼마나 유지하느냐에 고객사 이탈 여부가 달려 있다.

- **mRNA 암백신 — 처방의와 지불자**: 흑색종 전문 종양내과의는 INTerpath-001 HR 수치가 Phase 2 수준으로 유지되면 키트루다 처방에 자연스럽게 병용을 추가할 유인이 생긴다. 지불자는 개인 맞춤 제조 특성상 높은 약가와 OS 데이터 성숙 전까지 전면 급여 결정을 미룰 것으로 분석된다.
