### 3. ESMO 2026 개막 D-1 — INTerpath-001 mRNA 암백신, SAFFRON 폐암 조합 데이터 임박

**Key Point (객관):** ESMO 연례 학술대회 10/23 마드리드 개막. 핵심 LBA: ① LBA1 INTerpath-001(10/24 17:30 KST) — Moderna+MSD, 인티스메란 오토젠+키트루다 vs 키트루다 단독, 완전절제 고위험 흑색종 Phase 3, N=1,137명, RFS·DMFS HR 첫 공개. Phase 2 HR 0.51(Phase 2 출처 기준). ② LBA6 SAFFRON(10/25) — AstraZeneca+HUTCHMED, 오시머티닙+사볼리티닙 vs 백금 화학요법, EGFR+MET 폐암 Phase 3, N=338명. ③ Incyte INCB161734 KRAS G12D(10/25) Phase 1 오럴.
출처: [ESMO 공식](https://esmo.org/meeting-calendar/esmo-congress-2026) | [CUREToday](https://www.curetoday.com/view/esmo-2026-preview-5-late-breaking-trials-patients-should-watch) | [BioSpace/Incyte](https://www.biospace.com/press-releases/incyte-data-to-be-highlighted-in-four-rapid-oral-presentations-at-the-european-society-for-medical-oncology-esmo-congress-2026-support-efforts-to-improve-outcomes-in-difficult-to-treat-cancers)

**구도에 주는 의미(R&D 전략 시각):**
- **mRNA 암백신(INTerpath-001):** Phase 3 결과는 mRNA 모달리티가 감염병(코로나)에서 종양학으로 확장 가능한지의 분수령이다. Moderna 입장에서는 코로나 이후 파이프라인 다각화의 핵심 베팅. 결과가 Phase 2 수준(HR 0.51)을 유지하면 신보조/보조 흑색종 치료 패러다임 전환 — 면역항암제 단독 대비 복합 전략의 우위를 처음 Phase 3에서 입증하는 사례가 된다.
- **SAFFRON(EGFR+MET):** 오시머티닙+사볼리티닙 조합은 EGFR 변이 비소세포폐암에서 MET 바이패스 내성 경로를 선제 차단하는 '선봉 조합(upfront combination)' 전략. AZ가 NDA를 이미 제출(9/28~29)했다는 점은 Phase 3 결과에 자신이 있음을 시사한다. 시험 결과가 긍정적이면 EGFR 폐암 1차 치료 표준이 단독 TKI에서 TKI+METi 조합으로 이동.
- **KRAS G12D(Incyte):** KRAS G12C(소토라십·아다그라십)에 이어 G12D까지 직접 억제제 개발이 진행되면 CRC·PDAC(췌장암) 수요가 크게 열린다. Phase 1이므로 안전성·용량 데이터가 주목 포인트.

**전술적 반응 vs 구조 변화:** mRNA 암백신 Phase 3 결과가 양호하면 구조적 변화. 모달리티 자체의 신뢰도가 달라지며 빅파마의 mRNA 기반 항암 R&D 투자를 가속한다. SAFFRON 양성 결과도 구조적 — EGFR 폐암 치료 알고리즘이 바뀐다.

**인센티브 한 줄:** Moderna는 최대 암백신에 $25B+ 시장을 보고 있으며, MSD는 키트루다의 특허 만료(~2028) 이전에 조합 데이터를 확보해 수명 연장(lifecycle management)을 노리는 구조다.

**구도에 주는 의미:** 기존 CHB 치료(뉴클레오사이드 유사체)는 바이러스를 억제하지만 기능적 치유(HBsAg 소실)는 1% 수준으로 사실상 불가능했다. Hibsago 승인은 CHB 패러다임을 '만성 억제'에서 '기능적 치유 추구'로 전환하는 첫 발이다. 전 세계 CHB 환자 ~2.96억 명(원자료 수치) 중 NUC 치료 중 HBsAg ≤3,000 IU/mL인 환자 서브그룹이 1차 대상.

**인센티브 한 줄:** GSK(+Ionis)는 CHB에서 기능적 치유 시장을 선점함으로써 RNAi(Arrowhead, Vir Biotechnology)·캡시드 억제제 경쟁사 대비 클래스 첫 승인자 지위를 확보하는 포지셔닝이다.

- 강세 근거: 일본 이미 승인, FDA 3중 지정(우선심사·돌파구치료제·Fast Track), 위약 대비 치유율 19% vs 0%. 승인 시 CHB 기능적 치유 최초 치료제 프리미엄.
- 약세 근거: 적용 대상이 HBsAg ≤3,000 IU/mL 서브그룹으로 좁음 → 대규모 CHB 전체 시장으로 확장되기까지 시간. CRL(완전응답서한) 발행 시 주가 조정.

**테마 4 — Moderna(MRNA) INTerpath-001 이벤트(10/24)**
- 강세 근거: Phase 2 HR 0.51이 Phase 3에서 유지 또는 개선되면 mRNA 항암 플랫폼 재평가. 파이프라인 다각화 성공 증거.

**국내외 연결 고리:**

## 수요 관점 (Demand)

### A. GSK Hibsago (bepirovirsen) — CHB 기능적 치유

**환자:**
1. **Job**: CHB 환자(특히 NUC 장기 복용 중, HBsAg ≤3,000 IU/mL 군) — 현재 치료는 바이러스를 억제하지만 완치(HBsAg 소실)에 이르지 못한다. '평생 복약'에서 벗어나고 싶은 미충족 수요.
2. **대안 대비 우위**: 기존 NUC(엔테카비르·테노포비르) 기능적 치유율 ~1% vs bepirovirsen 19% — 동일 접근 불가능한 차원. 대안은 사실상 없음(RNAi 약제도 임상 진행 중).
3. **지불의향**: 완치 가능 치료제에 대한 환자 지불의향은 높으나, 주사제(피하) 24주 치료 비용이 급여 적용 여부에 달림.
4. **채택 장벽**: HBsAg 정량 진단 필요(≤3,000 IU/mL 선별) → 진단 접근성이 실제 처방 풀을 제한. 주사 치료(피하, 24주)에 대한 순응도.

**처방의:**
1. **Job**: CHB 가이드라인을 따라야 하는 간염 전문의 — 기능적 치유를 달성할 수 있는 치료 옵션 부재가 오랜 미충족 수요.
2. **대안 대비 우위**: B-Well 데이터(19% vs 0%)는 임상적으로 강력한 차별점. 가이드라인 개정 시 1차 또는 2차 치료 편입 가능.
3. **지불의향(처방 결정)**: FDA 승인 + 가이드라인 편입이 처방 허들의 핵심. 일본 승인(이미 완료)이 선례.
4. **채택 장벽**: HBsAg 정량화 검사 표준화, ASO 클래스 장기 안전성 데이터 축적 필요, 환자 선별 기준 학습 곡선.

**지불자(보험·급여):**
1. **Job**: 비용 효과적인 치료 급여 — 기능적 치유가 달성되면 장기 NUC 처방 비용 절감 논리 가능.
2. **대안 대비 우위**: 1회 치료 코스(24주)로 기능적 치유 달성 시 평생 NUC 비용 대비 비용 효과 계산 가능(구체 약가 미공개, 추정 불가).
3. **지불의향**: 지불자는 ICER 분석 요구 예상. 서브그룹(HBsAg ≤3,000) 좁은 적응증은 급여 협상 레버리지를 높일 수 있음.
4. **채택 장벽**: 약가 협상(GSK·Ionis 공동 개발 → 비용 회수 필요), 19% 치유율(81%는 치유 안 됨)의 급여 정당성 논쟁 가능.

### B. mRNA 암백신 INTerpath-001 (Moderna + MSD) — 흑색종

**환자:**
1. **Job**: 완전 절제 고위험 흑색종 환자(Stage IIB~IV) — 수술 후 재발·원격 전이 두려움, 키트루다 단독보다 더 강력한 보조치료 필요.
2. **대안 대비 우위**: Phase 2 HR 0.51(재발·사망 위험 49% 감소, Phase 2 출처 기준). 개인 맞춤형 네오항원 mRNA 백신(인티스메란 오토젠) + PD-1 체크포인트 조합 — 기존 표준(키트루다 단독)에 없는 능동면역 기전 추가.
3. **지불의향**: 개인 맞춤 제조(tumor sequencing → 백신 제작)로 생산 비용이 매우 높을 것으로 추정. 급여 적용 여부가 실제 접근성의 관문 — Phase 3 OS(전체 생존) 데이터 없이는 지불자 설득 어려울 수 있음.
4. **채택 장벽**: 개인 맞춤 제조 리드타임(수주), 냉동 보관·물류, 종양 조직 생검 의존성. Phase 3 HR이 Phase 2보다 희석되면 임상적 유의성 논란.

**처방의:**
1. 흑색종 전문 종양내과의 — 보조치료 강화 옵션 필요. Phase 3 결과 + ESMO LBA 발표 후 가이드라인 검토 사이클 진입.
2. 개인 맞춤 백신 처방 프로세스(생검→제조→투여)는 기존 표준 항암제 대비 새로운 워크플로 학습 비용 수반.
