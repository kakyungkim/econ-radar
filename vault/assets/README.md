# econ-radar — logo mark

레이더 스코프(동심원 + 스윕 라인)와 우상향 성장 벡터를 결합한 미니멀 마크.
매일 경제·바이오·AI를 스캔하며 성장 신호(펄스 노드)를 포착한다는 의미.

## 파일
- `logo.svg` — 마스터 마크 (slate 아크 + emerald 스윕). 밝은 배경용.
- `logo-mono.svg` — 단색 버전. `currentColor`를 사용하므로 부모 텍스트 색을 따라감.
  (`<img>`로 임베드 시 기본 `#0f172a`로 폴백, 인라인 임베드 시 `color`로 제어 가능.)
- `logo-16/32/64/256/512/1024.png` — 투명 배경 렌더(헤더/파비콘/앱 아이콘용).

## 팔레트
| 역할 | HEX | 비고 |
|---|---|---|
| 레이더 아크 (slate) | `#334155` | opacity 0.32 / 0.58 / 0.90 단계 |
| 성장 벡터 / 펄스 (emerald) | `#10b981` | 포인트 컬러 |
| 모노 기본색 | `#0f172a` | slate-900 |

emerald/slate 조합은 색맹 사용자에게도 명도 대비로 구분되며, 단색으로도 형태가 유지됨.

## 사용
- 헤더 좌측 아이콘: `width/height` 40~48px 권장, 밝은 배경(slate-100/white).
- 단색이 필요하면 `logo-mono.svg`를 인라인으로 넣고 부모에 `color:`를 지정.
- 외부 폰트/이미지 의존성 없음. 자체 완결형.

## 렌더 재생성
헤드리스 Chrome으로 HTML 래퍼를 거쳐 벡터를 목표 크기로 스케일 후 스크린샷.
(SVG의 고정 width/height 때문에 Chrome `--screenshot` 직접 사용 시 업스케일되지 않으므로 HTML 래퍼 사용.)
