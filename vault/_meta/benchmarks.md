# econ-radar 벤치마킹 조사

> 목적: 경제 뉴스지를 "한 번 훑어보듯"이 아니라 **더 깊이 있게** 다루도록 econ-radar의 깊이·구조·문체·기능을 끌어올린다.
> 조사 방식: 웹 검색(WebSearch/WebFetch)으로 실제 매체·도구의 공개 정보 확인.
> 관련 문서: [[improvement-log]], `CLAUDE.md`(3렌즈: 산업구조·투자·커리어 / 바이오·AI 가중)

## A. 깊이 있는 경제·산업·바이오·AI 뉴스레터·분석 매체

각 항목: **무엇을 / 구조·길이·문체 / econ-radar가 훔쳐올 것**.

### A-1. The Economist — Espresso & The World in Brief
- **URL**: https://www.economist.com/espresso · https://muckrack.com/media-outlet/TheEconomistEspressoNewsletter
- **무엇을**: 매 평일 아침, 그날의 핵심 5개 스토리 + 세계 동향 요약 + 시장·환율 업데이트. 미주/유럽/아시아 3개 판으로 발행.
- **구조·길이·문체**: 스토리당 약 150단어, 모바일 1화면에 딱 맞춤("에스프레소 한 잔" 비유). 상단 오디오 브리핑, '오늘의 차트', '오늘의 팩트' 같은 인터랙티브 요소. **유한한 분량(finite format)** — 다 읽으면 "끝났다"는 완결감을 준다.
- **훔쳐올 것**: ① 항목당 분량 상한(예: 핵심 5건은 각 150~200단어로 강제) → 무한 스크롤이 아니라 **완결되는 데일리**. ② '오늘의 차트/팩트' = econ-radar의 **숫자 해설 박스** 1개 고정. ③ 3개 권역판 발상 → 우리는 "거시/산업/바이오·AI" 렌즈별 짧은 묶음.

### A-2. Bloomberg — Money Stuff (Matt Levine)
- **URL**: https://www.bloomberg.com/account/newsletters/money-stuff · https://mattlevine.co/work
- **무엇을**: 매 평일 오후, 금융 뉴스 약 5건을 골라 깊게 해부. 인센티브·구조로 사건을 설명.
- **구조·길이·문체**: "바에서 나누는 빠른 대화 + 다정한 강의" 톤. 가상의 대화, 신조어, 각주, 농담을 섞되 **정밀함과 구조적 명료함**은 유지. 핵심 통찰: *"시장을 스펙터클이 아니라 건축물(architecture)로 본다 — 헤드라인 밑에 깔린 논리(incentive)를 찾는다."* 독자가 자기보다 많이 안다고 가정 → 잘난 척 없이 친절.
- **훔쳐올 것**: ① **"왜 이렇게 설계됐나(인센티브)"** 한 줄 — 사건마다 누가 무슨 동기로 움직였는지. ② 어려운 개념을 **가상 문답**으로 풀기("그럼 이게 왜 문제냐면…"). ③ 매일 같은 시간 같은 톤 → econ-radar의 **🗣 오늘의 화제**를 이 보이스로(설명 가능한 깊이 + 약간의 유머).

### A-3. Stratechery (Ben Thompson)
- **URL**: https://stratechery.com/ · https://stratechery.com/about/
- **무엇을**: 기술의 비즈니스·전략·영향. 데일리 업데이트(뉴스→전략적 추론) + 긴 에세이(비즈니스 모델·플랫폼 경제 해부).
- **구조·길이·문체**: 뉴스를 **전략적 추론(strategic inference)**으로 변환. Aggregation Theory 등 **반복되는 분석 프레임워크**를 어휘처럼 사용. *전술적 반응 vs 시장 구조를 바꾸는 전략적 수*를 구분하라고 독자에게 강조. 속도보다 깊이, 트렌디함보다 맥락.
- **훔쳐올 것**: ① **재사용 프레임워크** — econ-radar도 바이오/AI 해석에 고정 렌즈(파이프라인·모달리티·약가·자본배분 = CLAUDE.md의 신약개발 총괄 시점)를 매번 적용. ② "이건 전술이냐 구조 변화냐" 질문을 투자·산업 항목에 붙이기. ③ 단발 뉴스를 **누적 개념(MOC/주제 노트)에 연결** → 우리 옵시디언 강점과 정확히 일치.

### A-4. Axios — Smart Brevity (Pro Rata 등)
- **URL**: https://www.axios.com/smart-brevity · https://help.axios.com/hc/en-us/articles/36222626161435
- **무엇을**: "더 적게 써서 더 많이 전달". 뇌과학 기반 포맷.
- **구조·길이·문체**: 정해진 헤더 — **"What's new" → "Why it matters" → "Go deeper"**. 업데이트당 300단어 미만, 문단은 1~2문장, 굵게 처리로 시각적 앵커. 평균 읽기 시간 40% 단축. 시선추적 연구: 눈은 흥미로운 지점을 찾을 때까지 텍스트를 표본만 훑다가 그제서야 정독.
- **훔쳐올 것**: ① **"Why it matters(왜 중요한가)"를 모든 항목의 필수 1줄로** — 깊이의 핵심 장치. ② **"Go deeper(더 파기)"** = 1차 자료 링크/추가 읽을거리 라인. ③ 핵심 굵게 + 1~2문장 문단으로 스캔 가능성 확보(깊이 ≠ 장황함).

### A-5. Exponential View (Azeem Azhar)
- **URL**: https://www.exponentialview.co/ · https://www.azeemazhar.com/newsletter
- **무엇을**: AI·기술 전환의 영향. 학제간(interdisciplinary) 연구 그룹이 만드는 "가까운 미래의 야전 교범".
- **구조·길이·문체**: *"스토리가 아니라 지도(maps)를 만든다"* — 개별 사건이 아니라 흐름의 구조를 그림. 가속의 시대를 이해하기 위한 맥락 제공.
- **훔쳐올 것**: ① **"지도화"** — 오늘 뉴스 3건을 한 흐름(예: AI 자본지출 사이클)으로 묶어 큰 그림 1단락. ② 학제간 연결(경제×기술×규제) → 우리의 3렌즈 교차 해석에 직접 반영.

### A-6. Import AI (Jack Clark)
- **URL**: https://jack-clark.net/ · https://importai.substack.com/
- **무엇을**: 주간, 최첨단 AI 연구 논문 기반 분석. 각 이슈에 논문 요약 여러 개 + 끝에 짧은 SF 단편(기술의 함의를 상상).
- **구조·길이·문체**: 논문 읽기 → 요약 → **"Why this matters"**(왜 중요한지)를 매 항목에 붙임. arXiv 원문·데이터셋·프로젝트 사이트 링크. 통제/정렬 같은 거시 함의까지 끌어올림.
- **훔쳐올 것**: ① **1차 자료(논문·IR·보도자료·규제기관) 직접 링크** — improvement-log의 "1차 출처 검증" 약점을 정확히 보완. ② 단순 요약이 아니라 "왜 중요" + "더 큰 함의"를 매번. ③ 끝에 짧은 시나리오/상상 = 우리 투자 파트의 "시나리오·리스크"와 호응.

### A-7. 바이오·제약: Endpoints News · STAT(The Readout) · Fierce
- **URL**: https://endpoints.news/ · https://www.fiercebiotech.com/ · https://www.fiercepharma.com/ · (참고: https://lifescivoice.com/pharma-and-biotech-news-websites-2026/)
- **무엇을**: Endpoints = 바이오·제약 "사이언스·사람·돈". STAT = 헬스·의학 심층 보도/탐사(The Readout 뉴스레터). Fierce = 임상·승인·FDA·딜 속보.
- **구조·길이·문체**: Fierce/BioPharma Dive = 빠른 속보. **Endpoints·STAT = 심층 + 일부 페이월**. STAT은 짧은 브리프부터 장문 탐사·전문가 칼럼까지 스펙트럼.
- **훔쳐올 것**: ① **속보(Fierce형) vs 심층(STAT형) 두 레이어 구분** — econ-radar 바이오 항목을 "오늘 일어난 일" + "전략적으로 뭘 의미하나"로 분리. ② 임상 readout·승인·딜을 **신약개발 총괄 시점**(파이프라인 위치, 모달리티, 경쟁/파트너십)으로 한 단계 더 해석. ③ 페이월 항목은 1차 보도자료·IR로 우회 검증(improvement-log 교훈).

### A-8. 한국어 뉴스레터 — 미라클레터 · 어피티 · 순살브리핑 · 부딩
- **URL**: 미라클레터 https://www.instagram.com/mirakle.letter/ · 어피티 https://uppity.co.kr/ · 순살브리핑 https://soonsal.com/ · 부딩 https://www.booding.co/
- **무엇을 / 문체**:
  - **미라클레터**(매경): CEO·혁신 관심층. 글로벌 트렌드·테크·빅테크 주식·리더십. 어려운 AI·로봇을 쉽게 풀이.
  - **어피티(UPPITY)**: 2030 직장인. 금융·경제 이슈를 **일상 언어**로. 평일 오전 8시.
  - **순살브리핑**: 글로벌 금융·경제에서 **"살코기만 발라" 전달**(모건스탠리 출신). 매일 오전.
  - **부딩(BOODING)**: 밀레니얼 부동산. 딱딱한 글 대신 **그림·일러스트** 활용, 실수요자에게 실용적.
- **훔쳐올 것**: ① **한국어 일상 톤**(어피티) — 해외 기사 번역 시 번역체 제거, 구어체로. ② **"살코기만"**(순살) — 항목당 핵심만, 군더더기 컷. ③ **친근한 비유/시각요소**(부딩·미라클) — 어려운 바이오·거시를 비유 1개로. ④ 발송 리듬(정해진 시간) — 데일리 완결감.

## B. 유사 'AI 뉴스 다이제스트/리서치' 도구 (기능 벤치마킹)

각 항목: **핵심 기능 / 개인화·요약·출처 처리 / econ-radar 참고점·차별화**.
> econ-radar의 구조적 차별화: **개인 지식자산화(옵시디언 vault) + 누적 MOC + 저술(블로그·책) 연결**. 아래 도구 대부분은 "읽고 끝" — 우리는 "읽고 → 자산화 → 저술".

### B-1. smol.ai — AI News (swyx)
- **URL**: https://news.smol.ai/ · https://buttondown.com/ainews · 소스 추출 도구: https://github.com/ThomsenDrake/ainews-source-extractor
- **핵심 기능**: 매일 AI 관련 Discord·Reddit·X를 LLM 리서치 에이전트가 요약(9 서브레딧, 449 트위터, 29 디스코드·223 채널·5,116 메시지 → 약 491분 읽기 절약). **99%를 커스터마이즈 가능한 리서치 에이전트가 생성**, 오픈소스.
- **출처 처리**: 커뮤니티 원천 메시지를 직접 집계·요약, 링크 보존.
- **참고점**: ① **에이전트 파이프라인으로 다출처 자동 집계** = 우리 news-scout와 동일 발상 → 소스 수·채널을 명시적 카운트로 관리(투명성). ② NotebookLM으로 소스 import하는 보조 도구 존재 → econ-radar도 **그날 소스 URL 묶음을 vault에 저장**(재현성).
- **차별화**: smol은 커뮤니티 잡음 집계가 강점이나 **자산화·전략 해석은 없음**. 우리는 신뢰 경제지 우선 + 3렌즈 해석 + 옵시디언 누적.

### B-2. Perplexity — Discover / Pages / Memory
- **URL**: https://www.perplexity.ai/ (Discover) · Obsidian용 데일리 브리핑 쿡북: https://docs.perplexity.ai/docs/cookbook/showcase/daily-news-briefing
- **핵심 기능**: Discover = 트렌딩 토픽 포털(요약 + 원문 링크). 클릭하면 요약 + 후속 질문 가능. **Memory**로 과거 선호 기억, 프로필에 관심사 입력해 개인화. 3초 내 인용 포함 요약.
- **출처 처리**: 여러 소스 청크를 LLM이 종합, **사실마다 출처 인용**.
- **참고점**: ① **사실 단위 인라인 인용** — 우리 뉴스레터도 수치·주장마다 출처 표기(improvement-log "출처 없는 수치 금지"와 일치). ② 프로필 기반 개인화 → econ-radar의 "북극성"(신약개발 총괄·투자 시작·일의 미래)을 매번 주입. ③ **Obsidian 데일리 브리핑 쿡북 존재** = 우리와 가장 가까운 레퍼런스, 파이프라인 참고 가치 큼.
- **차별화**: Perplexity는 범용 검색 답변. 우리는 **도메인 고정(경제·바이오·AI) + 누적 자산 + 저술 출력**.

### B-3. Google NotebookLM
- **URL**: https://notebooklm.google.com/ · 오디오 오버뷰: https://blog.google/technology/ai/notebooklm-audio-overviews/
- **핵심 기능**: **소스 그라운디드(closed corpus)** — 업로드한 자료에서만 답하고 **할루시네이션 억제 + 인용 링크**. 산출물: 요약·브리핑·**오디오 오버뷰(AI 2인 대담)**·마인드맵·리포트. 80개+ 언어.
- **출처 처리**: 답변이 항상 내 소스에 묶이고 클릭 가능한 인용.
- **참고점**: ① **소스 그라운딩** = econ-radar 신뢰성의 핵심 모델 — 그날 수집 소스만으로 작성, 외부 추정 금지. ② **오디오 오버뷰** → 데일리 뉴스레터의 "오디오 브리핑" 버전(Espresso도 동일) 아이디어. ③ 마인드맵/리포트 다형 출력 → 우리 report-renderer(HTML)·trend-synthesizer와 호응.
- **차별화**: NotebookLM은 사용자가 소스를 매번 수동 투입. 우리는 **에이전트가 매일 자동 수집 + 영구 vault 누적 + 저술까지**.

### B-4. Feedly + Leo AI
- **URL**: https://feedly.com/ (Leo) · https://futuretools.io/tools/feedly-leo
- **핵심 기능**: Leo = AI 리서치 어시스턴트. **토픽·키워드 우선순위화, 중복 뉴스 디둡(dedup), 무관 정보 뮤트, 요약**. 사용자가 예시·피드백으로 학습시킴.
- **참고점**: ① **디둡** — 같은 사건 여러 매체 보도를 1건으로 병합(improvement-log의 '일일/주간 경계' 혼선 완화). ② **뮤트/우선순위** = 우리 비중 가이드(바이오·AI 40~55%)를 룰로 구현. ③ 피드백 학습 → improvement-log가 사실상 우리의 "피드백 루프".
- **차별화**: Feedly는 피드 필터링까지. 우리는 **필터링 후 전략 해석 + 자산화**.

### B-5. Ground News (편향 비교)
- **URL**: https://ground.news/ · 블라인드스팟: https://ground.news/blindspot
- **핵심 기능**: 한 사건을 **Left/Center/Right로 나란히** 비교, 편향·팩트 등급(All Sides·Ad Fontes·MBFC 기반). **Blindspot** = 한쪽만 보도하는 사각지대 표시.
- **참고점**: ① **반대 시각/다관점 박스** — econ-radar에 "이 뉴스의 다른 해석/반론" 1줄 추가 → 깊이의 강력한 장치. ② 투자 파트에 **강세론 vs 약세론** 양면 제시(권유 금지 원칙과도 합치). ③ "한쪽만 보도" 감지 → 우리도 **소스 쏠림 경고**.
- **차별화**: Ground는 정치 편향 축. 우리는 **투자/산업 논쟁의 양면**(낙관/비관, 수혜/피해)으로 변용.

### B-6. Artifact (종료) — 실패에서 얻는 교훈
- **URL**: https://techcrunch.com/2024/01/18/why-artifact-from-instagrams-founders-failed-shut-down/ · https://newsletter.failory.com/p/why-artifact-failed
- **무엇이었나**: 인스타 창업자들의 AI 개인화 뉴스앱(2023~2024). AI로 피드 큐레이션·요약·낚시성 제목 중화.
- **왜 실패**: ① 시장이 충분히 크지 않음·미국 밖 성장 정체. ② **AI 요약이 원문 클릭을 줄여** 퍼블리셔 수익·생태계 약화(요약의 역설). ③ 더 나은 읽기 경험에 집중하지 못하고 트위터·핀터레스트 기능까지 욕심. ④ 좋은 AI는 있었으나 **기존 생태계/유저 베이스 부재**.
- **econ-radar 교훈**: ① 우리는 **대중 시장이 아니라 1인 지식자산** — Artifact의 시장규모 실패가 우리에겐 무관(개인 도구라 강점). ② **요약의 역설 회피** = 요약으로 끝내지 말고 **원문 링크 + 내 해석/노트로 부가가치** → 옵시디언 자산화가 정확히 이 해법. ③ 기능 욕심 금지 — econ-radar는 "깊이 있는 데일리 + 자산 누적"에 집중, SNS화 금지.

## econ-radar에 바로 반영할 8가지 (체크리스트)

깊이·구조·문체·기능을 한 데 묶은 실행 항목. 다음 실행에서 적용하고 [[improvement-log]]에 결과 기록.

- [ ] **1. (구조) "Why it matters" 필수화** — 모든 핵심 항목에 *왜 중요한가* 1줄 강제(Axios). 깊이의 1번 장치.
- [ ] **2. (깊이) "Go deeper / 1차 자료 링크"** — 항목마다 논문·IR·보도자료·규제기관 원문 링크(Import AI·Perplexity). improvement-log의 1차 출처 약점 직접 보완.
- [ ] **3. (구조) 항목당 분량 상한 + 완결되는 데일리** — 핵심 5건 각 150~200단어, 다 읽으면 끝(Espresso). 무한 스크롤 금지.
- [ ] **4. (깊이) 재사용 전략 프레임 적용** — 바이오는 신약개발 총괄 렌즈(파이프라인·모달리티·약가·자본배분), 투자는 "전술이냐 구조 변화냐"(Stratechery).
- [ ] **5. (문체) 한국어 일상 보이스 + 인센티브 한 줄** — 번역체 제거·구어체(어피티), "누가 무슨 동기로"(Levine), 어려운 개념은 가상 문답/비유(미라클·부딩).
- [ ] **6. (깊이) 반대 시각 / 양면 박스** — 투자·산업 항목에 강세 vs 약세, 수혜 vs 피해 1줄(Ground News). 권유 금지 원칙과도 합치.
- [ ] **7. (기능) 디둡 + 비중 룰 + 소스 카운트** — 같은 사건 병합, 바이오·AI 50~55% 룰화, 그날 소스 URL 묶음을 vault에 저장(Feedly Leo·smol.ai). 재현성·투명성.
- [ ] **8. (기능/철학) 요약의 역설 회피 = 자산화로 끝맺기** — 요약으로 멈추지 말고 원문 링크 + 내 해석 노트 + MOC 연결로 부가가치(Artifact 교훈 + 우리 옵시디언·저술 강점). 🗣 오늘의 화제는 "남에게 설명 가능한 깊이"로.
