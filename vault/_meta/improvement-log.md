# 개선 기록 (improvement-log)

하네스를 실제로 돌린 뒤 빠진 소스, 약했던 분야, 고칠 점을 여기에 남긴다. 다음 개선의 근거다.

## 양식
```
## YYYY-MM-DD
- 무엇이: (예: 바이오 해외 소스에서 STAT 기사 누락)
- 왜: (paywall / 검색 누락 / 비중 부족)
- 어떻게 고칠지: (news-collection 소스 목록에 추가 등)
```

## 2026-06-09
- 하네스 신규 구축 완료. 첫 실행 전.
- 확정된 운영 방침:
  - 소스 = 신뢰 경제지(국내외) 우선, 해외 기사 한국어 번역.
  - 투자 = 코스피 + 해외(미국 등), 정보·시나리오(권유 아님).
  - 커리어 = AI 시대 일의 미래(사라질/떠오를 직업).
  - 바이오 = 신약개발 총괄 전략 시점([[topics/신약개발전략]]).

- 첫 실행 후 점검할 것: 해외 소스 접근성(paywall), 제약/바이오/AI 비중, 오늘의 화제 난이도.
