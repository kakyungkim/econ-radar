# 실행 계측 (run-metrics)

데일리 파이프라인을 돌릴 때 **단계별 소요 시간·토큰**을 누적한다. 비용·병목을 보고 자동화/모델 선택을 판단하는 근거다.

## 계측 방법 (각 단계마다 계산 가능)
- 각 단계는 subagent로 돌고, 끝날 때 `subagent_tokens`(그 에이전트가 쓴 토큰)와 `duration_ms`(벽시계 시간)를 반환한다 → **단계별로 그대로 기록**한다.
- 주의:
  - 토큰 합계는 **가산적**(단계 토큰을 더하면 됨). 단, 오케스트레이터(메인 루프)가 쓰는 토큰은 여기 미포함 — subagent 합계는 하한선이다.
  - 시간은 **병렬 단계가 겹친다**. market∥company, renderer∥curator처럼 동시에 돈 단계는 합이 아니라 **max**로 잡아야 실제 벽시계에 가깝다. 아래 "벽시계(추정)"는 순차 단계는 합, 병렬 단계는 max로 계산.
  - 값은 실행마다 변동(뉴스량·재시도·웹 fetch 지연).
