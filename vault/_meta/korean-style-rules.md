# 한국어 문체 규칙·단어 사전 (사용자 전역 규칙 미러)

사용자 전역 규칙 `~/.claude/rules/writing-style.md`를 레포로 옮긴 것. 클라우드 루틴(레포만 접근)에서도 윤문에 적용되게 한다. style-critic·newsletter-editor는 `korean-style-samples.md`(실제 기사 표본)와 **이 파일을 함께** 의무 참조한다. 원본 전역 규칙이 갱신되면 여기도 동기화한다.

## 산문 문체 규칙
1. **자연스러운 한국어.** 번역투·직역·어색한 표현 금지, 현업에서 실제 쓰는 말로. 영어 용어·관용구를 글자 그대로 옮기지 말 것.
2. **긴 문장은 끊어** 짧게. 한 문장 = 한 생각. (너무 짧은 두 문장은 연결어로 잇기.)
3. **em-dash(긴 줄표) 지양.** 마침표·괄호·쉼표·서술어로 대체. (숫자/합성어 en-dash `40-65%`는 무방.)
4. **남의 행위·사실은 평서형.** 보고서 자신의 의도만 "~고자 한다".
5. **가운뎃점(·) 절제.** 본문에서 3개 이상 나열은 쉼표나 '와/과'로 풀고, 짧게 굳은 2개 묶음(신약·바이오)만 ·. 표 안은 허용.
6. **약한 종결·사족 회피.** "~것이다", "같은 맥락이다", "~셈이다", "~뿐이다", 모호한 메타문장 금지 → 직접 서술문으로.
7. **문장 끝/제목 옆 괄호 부연 금지.** 본문으로 풀거나 분리. 단 "(그림 N)" 상호참조, 용어 첫 등장 1회 영어 병기 "동료심사(peer review)"는 허용.
8. **모호한 지시어·추상명사 구체화.** 가리키는 대상 명시.
9. **주어 명확·위치.** 주어를 빠뜨리지 말 것. 주어가 긴 부사구 앞에 떨어져 어색하면 서술어 가까이로 옮긴다.
10. **남의 연구를 본인 행위처럼 단정 금지.** "~한 것으로 보고되었다 / ~고 보고했다"로. (모델·도구가 주어로 명확한 능동은 허용.)
11. **선언형 단문 남발 금지·연결형 우선.** 못 박는 짧은 단문을 문단 끝 "결론 한 방"으로 떼거나 머리에 2~3개 연속 두지 말고, 앞 문장에 연결어(~므로/~며/~는데/~어/~다는 점에서)로 이어 한 호흡으로. 전환·강조용 단문은 리듬으로 남긴다.

## 단어·표현 사전 (치환·회피)
- **줄고 → 줄어들고** ("후보는 줄고" → "후보는 줄어들고").
- **같은 종결 표현 반복 회피.** 한 문단·인접 문장에서 동일 서술어를 되풀이하지 말고 맥락별로 변형("머문다" 반복 → "남는다 / 그친다 / 넘지 못한다").
- **AI 상투구 금지.** "A가 아니라 B"(사실 대조 "효능이 아니라 안전성"은 무방, thesis 한두 곳 의도적 대조만 허용), "~인 셈".
- **접속어 맥락 점검.** "또한/한편/따라서/게다가"가 실제 관계(추가·대조·인과)에 맞는지. 부연을 "또한"으로 잇지 말 것 → 접속어 빼거나 "~도/역시".
- **짧은 형용사 한 단어 종결 회피.** "…드물다.", "…크다.", "…적다."로 뚝 끊지 말고 완곡·부사로 늘리거나("많지 않다 / 드문 편이다") 앞뒤와 연결("…많지 않아 검증이 약하다"). 의도적 강조 단문은 예외.
- **시스템·팀이 "도는" → "돌아가는 / 일하는"** ("매일 도는 팀" → "매일 돌아가는 팀"). "작동하는"은 기계 느낌이라 사람·팀엔 부적합. (순환 뜻 "백로그가 도는"은 무방.)
- **쪼개다·갈라놓다 → 나누다 / 분리하다** ("일을 ~로 쪼개" → "~로 나눠"; "법으로 갈라놓았다" → "법으로 둘로 나눴다"). 구어적·극적 분리 동사보다 담백하게. (이산가족을 갈라놓다 같은 본래 뜻은 무방.)
- **몫 → 역할 / 할 일** (사용자가 "몫"을 잘 안 씀).
- **뜯어보다 → 나누어 보다 / 살펴보다**.
- **"사실을 받는다" → "사실만 다룬다 / 본다"** (번역투 회피).
- **목적어·연결어 빠뜨리지 말 것.** 무엇을 다루는지 목적어를 채우고, 절 사이를 "이때 / 따라서 / ~고"로 자연스럽게 잇는다.
- **"A는 B다"(명사 술어로 못 박기) 지양 → 동사절로 풀어 연결.** "기계가 만드는 건 초안까지다. 발행은 사람이 한다"(✗) → "기계는 초안까지 만들고, 발행은 사람이 하게 한다"(○). 동사로 풀어 "~고/~며"로 잇고 능동·사역 종결로.
- **과장된 드라마·문학적 서사 회피(특히 증시·시장).** "무너졌다 다시 일어섰다", "롤러코스터", "주저앉았다", "폭락 폭등", "패닉", "공포에 질렸다", "환호했다" 같은 극적 묘사 대신 담백한 금융 용어로: 급락/반등/급등락/조정/변동성 확대. (추상 은유 클리셰 "지형이 바뀐다"와는 별개로, 이건 *극적 서사*를 잡는다. W26 동향에서 "무너졌다 다시 일어섰다"·"롤러코스터"가 검수 게이트를 통과해 사람이 잡은 사례, 2026-06-28.)
- **"축"(axis)은 번역투 → 문맥에 맞는 한국어로.** "경쟁 축이 ~으로 옮겨갔다"의 "축"은 영어 axis 느낌이라 낯설다 → "경쟁의 **초점/승부처/무게중심**", "**성장 동력**/성장의 중심"처럼 문맥에 맞게. (좌표축 등 본래 뜻은 무방.)
- **"문턱을 넘다"는 비유적 → 문맥에 맞게 풀기.** "만성질환 문턱을 넘고"처럼 "넘다"로 쓰면 비유적이고 뒤 문장의 "진입했다"와 겹치기 쉽다 → "~에 **진입하다** / ~로 **영역을 넓히다**"로. (단 "문턱이 높다/낮다"=진입 장벽은 흔하니 유지.)
- **"담론에서 거래로 내려왔다" 류 어색한 비유 회피.** "담론/말잔치에서 거래로 내려왔다" 같은 표현은 어색 → "논의 단계를 넘어 실제 거래로 이어졌다 / 나타났다".
- **"시나리오에 넣어둔다"는 어색 → "염두에 둔다 / 가정에 포함한다 / 미리 고려한다".**
- **횟수를 헤드라인으로 내세우기보다 패턴으로.** "올해만 세 번"처럼 정확한 횟수를 강조하기보다 "올해 거듭됐다 / 잇따랐다"로 반복·패턴을 말하고, 구체 사례(이름)는 근거로 든다. 숫자 자체보다 흐름이 요점일 때.
