# 링크드인 본문

11월 첫 주, 다섯 달째 매일 자동으로 나가는 뉴스레터를 오랜만에 열어 봤습니다.

자동으로 돌아간다고 믿은 파이프라인은 정말 잘 돌고 있었을까요? 10월 한 달 동안 블로그 페이지 5개가 빠졌는데 배포 스크립트는 그때마다 "공개 완료"를 출력했습니다.

econ-radar는 Claude Code 클라우드 루틴으로 매일 저녁 한 호를 만드는 한국어 경제 뉴스레터입니다. 제약, 바이오, AI 비중이 크고 블로그와 텔레그램과 메일로 나갑니다. 6월에 자동 발행으로 넘긴 뒤로는 거의 들여다보지 않았습니다.

점검해 보니 세 곳이 조용히 틀리고 있었습니다.

발행 감시의 오알림. 밤 10시로 예약한 감시가 실제로는 다음 날 새벽에 돌면서 아직 없는 내일 호를 찾았고 매일 "누락"을 알리는 사이 진짜 누락 4건을 놓쳤습니다.

블로그 배포의 거짓 성공. 클라우드 세션이 저장소를 detached HEAD로 받는 탓에 git push가 새 커밋 대신 예전 커밋을 밀었는데 스크립트는 오류 없이 끝났습니다.

7월 기사 수치의 재사용. 10월 3일 호에 7월 기사의 코스피 8,000이 실렸습니다. 그날 실제 종가는 7,003.74였습니다. 사실 검증 에이전트는 원문 사이트에 접속하지 못한 채 "오류 0건"을 보고했습니다.

그래서 push 뒤에 원격 반영을 확인하게 하고 감시가 볼 날짜를 고쳤습니다. 시장 수치 대조 검사도 붙였습니다. 코스피, 미 국채 10년물, 원/달러를 실제 시세와 비교하는데 고치기 전 호에서는 잘못된 값 세 개를 모두 잡았고 고친 뒤에는 0건이었습니다.

성공 메시지와 실제 결과는 따로 확인해야 한다는 것을 이번에 다시 배웠습니다. 점검 과정과 그림은 첫 댓글의 블로그 글에 정리했고 메일과 텔레그램 구독 주소도 함께 적어 두었습니다.
