# 🗂 삼성바이오로직스 — 주제 지도(MOC)

> 범위: 삼성바이오로직스(207940) 전략·M&A·CDMO 역량 확장·고객사 현황 추적.

## 핵심 흐름
- **PolyPeptide Group 공개매수 87.92% 확정 — GLP-1 API CDMO 진입 확정**: 딜 규모 CHF 1.46B(약 2조2,000억원 추정), 주당 44.31CHF(시장가 대비 ~40% 프리미엄). 딜 종결·스위스 증시 상장 폐지 2026년 연말 예정.
- **기존 항체·ADC CDMO + 펩타이드 API = 원스톱 CDMO 구조 완성**: PolyPeptide는 스웨덴·벨기에·프랑스·미국·인도 5개국 생산 거점 보유. GLP-1 공급망 병목 상황에서 Novo Nordisk·Eli Lilly의 API 외부 의존도 증가.
- **통합 리스크와 장기 구조**: PMI(인수후통합) 기간 생산 연속성 유지가 기존 고객사 이탈 방지의 핵심. 빅파마 API 내재화 강화 시 외부 CDMO 수요 감소 구조적 위험.
