# 🗂 유망 기업·주목 플레이어 — 주제 지도(MOC)

> 2026-06-10부터 1층의 세 번째 렌즈가 '커리어'에서 '유망 기업'으로 교체됐다.
> 매일 주목할 기업·플레이어를 정보로 누적한다. 매수·매도 권유가 아니라 정보·시나리오·리스크로 정리한다. 최종 판단은 본인의 몫.

## 보는 축
- 무슨 일(이벤트)·왜 주목·지켜볼 점·R&D/경쟁 구도
- 모달리티·파이프라인 위치(바이오), 사업 구도·수익화 단계(테크)
- 자본 흐름(인수·라이선스·CAPEX)과 연결

## 핵심 흐름
- mRNA 종양학 플레이어가 상업화 트랙에 진입(6/12~) — 모더나·머크가 인티스메란 5년 데이터(흑색종 재발 49%↓)로 Phase 3 전환 시점에 섰고, BioNTech는 mRNA를 넘어 이중특이항체(NSCLC·난소암)로 전선을 넓힘. 관전 포인트는 Phase 3 중간분석·최종 OS 데이터·맞춤 제조 규모화.
- K-바이오 플랫폼사가 빅파마 검증을 통과하며 떠오름(6/12~) — 한미약품 랩스커버리(GLP-2 소네페글루타이드 L/O·하나증권 목표 71만원 상향), 오스코텍 세비도플레닙(아지오스 이전·Phase 3 설계 착수). '플랫폼이 팔린다'는 점이 단일 물질 거래와 다른 가치 신호.
- AI 인프라 플레이어를 보는 잣대가 칩·모델 다변화로 이동 — 구글·블랙스톤 TPU 합작사(2027년 500MW 목표)가 엔비디아 GPU 대안으로, MS 자체 모델 7종이 OpenAI 의존 축소로. 첫 외부 고객 확보·실제 경쟁력이 새 관전 포인트.
- 프런티어 모델사(오픈AI·앤트로픽)가 신모델과 상장을 동시에 들고 나오는 구도 — S-1의 매출·적자 구조가 가치 검증 지점.
- K-바이오 기업이 FDA 접점(라이선스 아웃·자체 임상·대미 생산)으로 동시에 떠오르되, 이중항체 자산은 OS 미충족 같은 임상 데이터 부담을 함께 안음(에이비엘바이오).
- 고객 렌즈 정착(6/11~): 각 기업 카드에 '1차 고객은 누구·왜 선택하나'를 단다(바이오는 환자·처방의·지불자 분해).
