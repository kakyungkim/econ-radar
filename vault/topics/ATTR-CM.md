# 🗂 ATTR-CM 파이프라인 — 주제 지도(MOC)

> 범위: 트랜스티레틴 아밀로이드 심근병증(ATTR-CM, transthyretin amyloid cardiomyopathy) 치료제 경쟁 구도. 스타빌라이저·RNA 억제제·소분자 세 갈래 임상 추적.

## 핵심 흐름
- eplontersen(AZ·Ionis, GalNAc-ASO) CARDIO-TTRansform 3상 1차 종점 미충족. 스타빌라이저(tafamidis) 병용 환자에서 추가 효익 없음 확인. 단독 코호트 HR 0.71은 ESC 8/28 전체 데이터 공개 시 견고성 확인 예정.
- 스타빌라이저(tafamidis, Pfizer Vyndamax/Vyndaqel) 표준요법 지위 재확인. ATTR-ACT 3상(2019) 이후 기준선.
- vutrisiran(Alnylam, siRNA) HELIOS-B로 ATTR-CM CV 아웃컴 개선 이미 입증. RNA 억제제 계열에서 임상 설계 차이(층화 변수)가 결과를 갈랐다.
- ESC 2026 핫라인(8/28, 뮌헨) — CARDIO-TTRansform 전체 데이터 공개 예정. AZ·Ionis의 적응증 재설정(스타빌라이저 미경험 환자) 전략 여부 결정 관문.
