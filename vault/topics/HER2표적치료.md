# 🗂 HER2 표적치료 — 주제 지도(MOC)

> 범위: HER2 양성 암종 표적치료 경쟁 구도. 이중파라토프 항체(biparatopic)·ADC·이중특이성 항체 모달리티 추적.

## 핵심 흐름
- Jazz Ziihera(zanidatamab, 이중파라토프 항체) PDUFA 8/25 D-2 — HER2+ 위장관선암(GEA) 1차 치료 sBLA. HERIZON-GEA-01 3상 OS 26.4개월·OS HR 0.72(P=0.0043). 승인 시 Jazz 종양학 포트폴리오 첫 진입.
- T-DXd(트라스투주맙 데룩스테칸, ADC, AZ·Daiichi Sankyo) 2차 치료에서 자리를 굳혔으나 1차 치료에서 zanidatamab과 경쟁 구도 형성 예상.
- 이중파라토프 기전(HER2 ECD2·ECD4 동시 표적)이 HER2+ GEA 1차 치료 OS 개선을 증명하면 HER2+ 유방암·다른 위장관암으로 적응증 확장 논거가 동시에 강화된다.
- 3제 병용(zanidatamab + tislelizumab + 화학요법) 독성 프로파일과 약가 총합이 실제 처방 채택 속도를 결정.
