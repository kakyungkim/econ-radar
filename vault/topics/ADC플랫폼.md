# 🗂 ADC 플랫폼 — 주제 지도(MOC)

> 범위: 항체-약물 접합체(ADC, Antibody-Drug Conjugate) 플랫폼 전략·임상 데이터·라이선스 딜·WCLC·ESMO 학회 데이터 추적. ADC 모달리티 일반([[topics/ADC]])과 달리, 이 파일은 플랫폼 경쟁 구도·학회 이벤트·K-바이오 연계에 집중.

## 핵심 흐름
- **WCLC 서울 2026(9/12~15) — ADC×IO·EGFR 데이터 집중 공개**: BioNTech pumitamig(PD-L1×VEGF-A)+elfetabart(B7H3 ADC) 1/2상. ORR 20%+ 여부와 ILD·irAE 독성 중첩 프로파일이 3상 설계 분기점. AZ-Dizal sunvozertinib EGFR 엑손 20 신규 데이터 동시 발표.
- **리가켐바이오 WCLC 모멘텀 절정 + 바이오파마 H1 M&A $96B**: K-ADC 후기 임상 자산에 빅파마 관심 지속. 연간 $250B+ M&A 페이스.
- **AZ-Dizal EGFR 엑손 20 $1.5B 라이선스 — EGFR 전체 변이 커버리지 완성**: 선불금 $600M + 마일스톤 $900M. WCLC 보조요법·1차 치료 데이터가 amivantamab(J&J) 처방 경쟁 구도를 결정.
