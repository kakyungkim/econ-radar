# 🗂 ADC 플랫폼 — 주제 지도(MOC)

> 범위: 항체-약물 접합체(ADC, Antibody-Drug Conjugate) 플랫폼 전략·임상 데이터·라이선스 딜·WCLC·ESMO 학회 데이터 추적. ADC 모달리티 일반([[topics/ADC]])과 달리, 이 파일은 플랫폼 경쟁 구도·학회 이벤트·K-바이오 연계에 집중.

## 핵심 흐름
- **ESMO 2026 ADC 학회 결산(10/27 폐막) — 바이오마커 전략이 승패를 가른다**: Pfizer SigVie-002(IB6·CEACAM5) nsq-NSCLC 전체 집단 OS 미달, 탐색적 분석에서 IB6 발현·반응 상관관계 불분명. AZ VOLGA(Nectin-4 ADC+더발루맙) MIBC EFS 49%·OS 42% 위험 감소. Merck sac-TMT(Trop-2) 자궁내막암·EGFR-m NSCLC·PD-L1 음성 NSCLC 1차 3중 Phase 3 한 학회 동시 발표.
- **발현 보편성·환자 선별이 핵심 설계 변수**: CEACAM5(발현·반응 상관관계 불명) 실패 vs Trop-2(고형암 전반 높은 발현)·Nectin-4(방광암 검증 완료) 성공의 대조. CDx 동반 개발 없이 전체 집단 OS를 1차 평가변수로 설계한 SigVie-002 실패가 ADC Phase 3 설계 교훈 반복 확인.
- **AZ 방광암·위암 ADC 이중 완성**: VOLGA(방광암 EFS·OS)·Sone-Ve(위암 CLDN18.2 OS 달성) + Takeda G-HOPE-001(CLDN18.2 위암) Phase 3 양성으로 위암 ADC 2파전 구도 확인.
