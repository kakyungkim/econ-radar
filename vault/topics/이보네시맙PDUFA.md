# 🗂 이보네시맙 PDUFA — 주제 지도(MOC)

## 핵심 흐름
- **PDUFA D-8(2026-11-06) — 이진 이벤트 카운트다운**: 중국 단독 임상(HARMONi Phase 3) PFS 양성·OS 미성숙. FDA의 중국 단독 데이터 수용 여부 첫 선례. 승인 시 AZ 오시머티닙(타그리소) NSCLC 2차 치료 독점 첫 균열. CRL 시 글로벌 임상 재진행 필요.
- **핵심 리스크**: OS 없는 PFS 단독 근거 허가 FDA 기조, 중국 단독 임상 데이터 미국 허가 선례 부재. 뇌전이 intracranial PFS 보완 데이터 제출 완료.
- **선례 의미**: 한국 바이오 기업들의 중국·아시아 단독 임상 데이터 미국 시장 진입 가능성 선례.
