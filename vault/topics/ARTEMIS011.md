# 🗂 ARTEMIS-011 — 주제 지도(MOC)

> 범위: 리스부타투그 레제테칸(risvutatug rezetecan, Ris-Rez) ARTEMIS-011 Phase 3 — B7-H3 ADC 골육종 임상 추적. B7-H3 ADC 플랫폼 전반은 [[topics/ADC플랫폼]] 참조.

## 핵심 흐름
- **ARTEMIS-011 Phase 3 양성(ESMO 2026) — B7-H3 ADC 두 번째 Phase 3**: 재발·불응 골육종 2차+(N=122), PFS 중앙값 5.5개월 vs 젬시타빈+도세탁셀 1.4개월(HR 0.33, p<0.0001). ORR 15% vs 2%, DCR 76% vs 33%. OS HR 0.51(미성숙, CI 0.21~1.23). FDA BTD·EMA PRIME·글로벌 희귀의약품 지정 보유.
- **글로벌 허가 경로의 핵심 과제**: N=122 중국 단일 Phase 3 글로벌 대표성 문제. GSK EMBOLD Sarcoma-202(글로벌 Phase 1b/2)가 전 세계 허가의 결정적 근거. OS 미성숙으로 성숙 데이터 필요.
- **파트너십 구조**: Hansoh 중국 BLA 준비, GSK ex-중국 글로벌 개발 분업. FDA BTD·EMA PRIME으로 빠른 글로벌 승인 경로 확보.
- **B7-H3 ADC 플랫폼 신뢰도 누적**: ARTEMIS-008(ES-SCLC OS HR 0.46)에 이어 두 번째 Phase 3 양성. 현재 B7-H3 Phase 3 수준 경쟁자 없음.
