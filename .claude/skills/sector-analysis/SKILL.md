# sector-analysis (3렌즈 분석 매뉴얼)

## 트리거
- raw 수집이 끝나 market-analyst / career-analyst가 분석을 시작할 때.
- "오늘 산업/투자/취업 관점으로 봐줘" 요청.

## 세 렌즈 정의
| 렌즈 | 담당 | 핵심 질문 |
| --- | --- | --- |
| 🏭 산업구조 | market-analyst | 누가 움직였나? 밸류체인 어디가 바뀌나? 경쟁·규제·공급망 구도는? |
| 💰 투자 | market-analyst | 테마는? 관련 섹터·종목(정보)? 리스크/기회? **국내(코스피)+해외(미국 등) 모두**, 국내외 연결 고리는? |
| 🧑‍💼 커리어·일의 미래 | career-analyst | AI 시대에 어떤 직업이 사라지고 떠오르나? 어떤 역량이 중요해지나? 일의 지형 변화는? |

## 수요 렌즈 (Demand) 오버레이 (모든 분석가 공통, (A) 단계)
세 렌즈가 "누가 돈을 버나"(공급·자본)에 치우치지 않게, 수요 쪽 **"누가 이걸 사고 쓰나, 왜?"**를 한 단 얹는다. 새 에이전트 없이 market-analyst·company-scout가 기존 분석에 수요 렌즈 블록을 단다. **작성 전 `vault/_meta/demand-lens.md`를 읽고** 그 기준대로 적용한다. 명확한 구매자가 없는 거시·금리 항목엔 억지로 달지 않는다.
- 핵심 항목·주목 기업에 JTBD 4줄: ① 누구의 어떤 문제(Job) ② 대안 대비 왜 이걸 고르나 ③ 누가 돈을 내나/지불의향 ④ 채택 장벽.
- **제약/바이오는 "고객"이 한 명이 아니다** — 환자·처방의·지불자(·병원/약국)로 갈라 본다. 지불자(급여·약가)가 상업적 성패의 관문. AI는 최종 사용자 ≠ 도입 기업 ≠ 개발자로 갈린다.
- 수요 렌즈도 매수·매도·입사 권유가 아니라 정보·시나리오. 출처 없는 수요·약가 숫자 금지.

## 작업 절차 (각 분석가 공통)
1. `vault/raw/news-YYYY-MM-DD.md`를 읽는다.
2. 관련 `vault/topics/*.md`를 읽어 과거 흐름과 이어 본다.
3. 자기 렌즈로 항목을 해석한다(특히 제약/바이오/AI는 더 깊게).
4. 각 해석에 근거 출처를 연결한다.
5. 이어질 주제를 `[[topics/...]]`로 표시한다.
6. `vault/analysis/{market|career}-YYYY-MM-DD.md`로 저장한다.

## 출력 형식
각 에이전트 카드의 출력 형식을 따른다. frontmatter에 `lens`, `tags`, `links` 포함.

## 품질 체크
- [ ] 모든 해석에 근거(출처/원본 항목)가 연결됐는가
- [ ] 매수·매도 권유, 특정 회사 보증 같은 금지 표현이 없는가
- [ ] 추정은 "추정"으로 명시했는가
- [ ] 제약/바이오/AI를 충분히 깊게 다뤘는가
- [ ] **수요 신호가 있는 핵심 항목·주목 기업에 수요 렌즈(Demand, JTBD 4줄)를 달았는가** (바이오는 환자·처방의·지불자 분해, 구매자 없는 거시는 생략)
- [ ] 이어질 주제를 MOC 링크로 남겼는가

## 깊이 기준 (benchmarks.md 반영)
좋은 경제·산업 분석 매체에서 가져온 깊이 장치다. 각 항목을 단순 요약에서 끝내지 말고 아래를 적용한다.
- **Why it matters 한 줄**(Axios): 사건마다 "왜 중요한가"를 한 줄로 명시.
- **1차 자료 직접 인용**(Import AI): IR·보도자료·규제기관·논문 원문을 링크. 2차 출처면 "재확인 권장" 표기.
- **양면 시각**(Ground News): 투자·산업 항목엔 강세 vs 약세, 기회 vs 리스크를 함께. 한쪽으로 몰지 않는다(권유 금지 원칙과도 합치).
- **재사용 전략 프레임**(Stratechery): "이건 일시적 전술인가, 구조 변화인가"를 매번 묻는다. 바이오는 파이프라인·모달리티·약가·자본배분 렌즈.
- **인센티브 한 줄**(Money Stuff): "누가 무슨 동기로 움직였나"를 짚는다.
- 항목당 분량은 끝맺음이 있게(과하게 늘어지지 않게). 깊이는 length가 아니라 맥락·근거·함의에서 나온다.

## 금지선 (위험 관리)
- 투자: "사라/팔아라" 금지. **정보·시나리오·리스크**로만. 사용자가 실제 투자를 하므로 최종 판단·책임은 본인에게 있음을 전제로, 한쪽으로 몰지 않고 리스크를 함께 제시한다.
- 커리어: 특정 회사 입사 보증·"이 직업은 사라진다" 단정 금지. **흐름·가능성·시나리오**로만.
- 둘 다: 출처 없는 수치·전망 생성 금지.

## 예외 상황
- 오늘 한 렌즈의 신호가 약하면 "오늘은 신호 약함 + 지켜볼 포인트"로 짧게.
