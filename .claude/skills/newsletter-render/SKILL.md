# newsletter-render (뉴스레터·HTML·푸시 매뉴얼)

## 트리거
- 분석이 끝나 뉴스레터를 엮을 때(newsletter-editor).
- 뉴스레터가 완성돼 HTML/푸시로 만들 때(report-renderer).

## 1) 뉴스레터 통합 (newsletter-editor)
- 출력 언어: **한국어**. 해외 출처 항목도 한국어로(고유명사 영문 병기).
- **2층 구조 (얕지 않게):**
  - **오늘 핵심 5가지** — 5건 요약(각 항목 원문 링크) + 섹션 한 줄. 이것만 봐도 흐름이 잡힌다. (제목은 명사로 끝나는 한국어. 영어 약어·부사형 라벨 금지) **각 항목에 "→ 왜 중요한가: …" 1줄 필수.** 3개로 줄이지 않는다 — 경제지를 훑는 폭은 항목 수에서 온다.
  - **🗣 오늘의 화제** — 토픽 하나를 남에게 설명할 수 있을 만큼 산문으로. 💬 한 줄 요약 + 🔗 블로그 소재 + 출처.
  - **🗽 오늘의 경제 영어** — 그날 뉴스에서 경제·비즈니스 영어 표현 2~3개. **단어 + 예문(문장)**: 오늘 사건을 비즈니스 영어 문장으로 옮기고 한국어 번역을 붙여 회화·토론에 쓰게 한다. 일반 단어장이 아니라 오늘 뉴스에서 뽑는다.
  - **더 깊이 보기(심층 분석)** — 🏭 산업구조 / 💰 투자(국내·해외, 기회·리스크 양면) / 🧑‍💼 커리어·일의 미래 / 🧪 전략 노트(의사결정자의 시선 — R&D·자본배분·모달리티. '신약개발 총괄' 같은 노골적 표현은 피한다). 분석가가 낸 깊이를 살려 배경·근거·시사점까지.
  - 🔗 이어지는 주제 → 출처(전체, 분야별 링크).
- **모든 항목에 원문 링크**(raw의 URL 사용). "본문 확인 필요"만 달지 말고 가능한 한 링크를 건다.
- 분석가의 깊이를 과하게 압축하지 않는다. 핵심 요약은 짧게, 심층은 충분히.
- 저장: `vault/daily/YYYY-MM-DD.md` (옵시디언 데일리노트).

## 문체(톤)·밀도·구성 — 모든 산출물 공통
- 사람이 쓴 것처럼 담백하게. AI 상투구 금지: "A가 아니라 B", "~인 셈", "~라고 할 수 있다", 과장된 구어체, 오글거리는 비유.
- 전문용어는 한국어(영문) 병기. 용어는 "블로그 소재"(="씨앗" 아님).
- **밀도·구성 레퍼런스 = 순살브리핑**(한 입 크기 구성, 군더더기 없음). 단 **친근한 말투를 베끼지 않고** 담백한 정보 톤을 유지한다.
- **카드뉴스(이미지 카드) 형식은 만들지 않는다.** HTML은 술술 읽히는 뉴스레터형 웹 리포트.

## 2) HTML 시각 리포트 (report-renderer)
- 저장: `vault/html/YYYY-MM-DD.html` (단일 파일, 브라우저로 바로 열기). ※ 동향 리포트(`vault/reports/`)와 헷갈리지 않게 일일 HTML은 `html/`에 둔다.
- TailwindCSS는 CDN으로 로드. 오프라인이면 스타일이 제한될 수 있음을 주석으로 안내.
- 정보 구조 (뉴스레터의 2층 구조를 그대로 반영):
  - 상단: 날짜 + `오늘 핵심 3가지`. (제목 아래 "더 깊이 보기를 펼쳐 보세요" 같은 사용법 문구는 넣지 않는다. 구조로 말한다.)
  - **🗣 오늘의 화제**를 가장 눈에 띄는 큰 카드로.
  - `더 깊이 보기`: 산업구조 / 투자 / 커리어 / 신약개발 총괄 시점을 **`<details>` 접이식 카드**로 — 기본은 한눈에 보이되 펼치면 심층까지. (산업구조는 기본 펼침 권장)
  - 분야 색 배지: 거시(회색)·바이오제약(초록)·AI(보라)·커리어(파랑).
  - 하단: 출처 전체 링크(클릭 가능), 해외 출처는 🌐 표시.
- 모바일 폭(375px)에서 텍스트 겹침·표 넘침·카드 깨짐이 없어야 한다.

## 3) 푸시용 메시지 (report-renderer)
- 저장: `vault/push/YYYY-MM-DD.md`.
- 형식:
  ```
  📈 econ-radar YYYY-MM-DD
  🗣 오늘의 화제: {토픽} — 한 줄 설명
  1) 핵심 한 줄
  2) 핵심 한 줄
  3) 핵심 한 줄
  🔗 [가장 중요한 기사 제목](URL)
  ```
- 푸시는 한눈에 채널이다. 짧게(메신저 한 화면), 자연스러운 문장으로. 깊이는 뉴스레터/HTML에서.

## 품질 체크
- [ ] 뉴스레터·HTML·푸시의 숫자가 원본 분석과 일치하는가(지어낸 수치 없음)
- [ ] 한국어로 자연스럽게 읽히는가, 해외 고유명사 병기됐는가
- [ ] HTML이 모바일에서 깨지지 않는가(직접 열어 확인 권장)
- [ ] 세 영역(산업/투자/취업)이 모두 들어갔는가
- [ ] 출처 링크가 살아 있는가

## 발송에 대한 경고
- report-renderer는 **파일만 만든다.** 메일·메신저 외부 발송은 사람 승인 뒤 오케스트레이터가 안내한다. 자동 발송 금지.
